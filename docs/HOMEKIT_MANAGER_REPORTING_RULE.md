# HomeKit Manager – Verbindliche Reporting-Regel

Diese Regel gilt ab Phase 5B.12 für sämtliche weiteren Arbeiten am HomeKit-Manager-Projekt.

Die abschließende Antwort besteht ausschließlich aus genau einem eingebetteten und vollständig
kopierbaren Markdown-Codeblock mit der Sprachkennung `markdown`. Der gesamte Bericht steht
innerhalb dieses einen Blocks. Es gibt außerhalb des Blocks keine Einleitung, Zusammenfassung,
Statusmeldung oder weitere Kommentare. Es gibt keine weiteren Codeblöcke und keine bloßen
Verweise auf Dokumentationsdateien.

Jeder Abschlussbericht verwendet exakt diese Reihenfolge:

1. `HomeKit Manager – Phase [Bezeichnung]`
2. `Ergebnis`
3. `GO / CONDITIONAL-GO / NO-GO`
4. `Durchgeführte Arbeiten`
5. `Änderungen`
6. `Testergebnisse`
7. `Produktiver Systemzustand`
8. `Sicherheitsprüfung`
9. `Offene Punkte`
10. `Nächster Schritt`
11. `Erforderliche Freigaben`
12. `Dokumentation`

Innerhalb des Blocks verwendet der Bericht normale Markdown-Überschriften, Tabellen und
Aufzählungen. Der Bericht enthält alle entscheidungsrelevanten Informationen direkt. Testergebnisse werden
als ausgeführt, fehlgeschlagen, übersprungen, nicht ausführbar oder nicht produktiv geprüft
gekennzeichnet. Eine lokale Abnahme wird nie als produktive Abnahme dargestellt.
