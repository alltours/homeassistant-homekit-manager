# Repository setup

This repository contains only the HomeKit Manager integration, its tests, and project documentation. The surrounding Home Assistant workspace contains unrelated dashboards, backups, databases, virtual environments, and historical evidence and was intentionally not copied.

The current public release is `v0.9.9`. The release series is intentionally limited
to `0.9.x`; historical `1.0.x` release and tag references were removed from GitHub on
26.10.2026 to prevent an obsolete higher version from being offered by HACS. The
underlying commits remain in Git history.

The earlier release candidate `1.0.1-rc1` had this 22-file archive checksum:

`2a50d9a78230de15ece49df2d25d4fd9f842e75f70d201beb37e36e0686aa93e`

No production Home Assistant files, `.storage` data, backups, access tokens, private keys, or local virtual environments belong in this repository.
